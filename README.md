# TSV 阅读器

一个轻量级、功能强大的 TSV（Tab-Separated Values）文件阅读器，专为翻译工作者和数据处理人员设计。所有数据处理均在本地完成，无需上传到服务器，保护您的数据隐私。

## ✨ 功能特性

### 📊 核心功能
- **文件上传**：支持拖放或点击上传 `.tsv`、`.txt`、`.csv` 文件
- **数据展示**：清晰美观的表格界面，支持大量数据浏览
- **本地处理**：所有数据在浏览器本地处理，不会上传到任何服务器

### 🔍 搜索与筛选
- **ID 筛选**：支持按第一列（ID）进行精确筛选
  - 支持单个 ID：`82`
  - 支持多个 ID：`82, 100, 150`
  - 支持范围筛选：`100-120`
  - 支持混合格式：`82, 100-120, 150`
- **全文搜索**：在所有列中搜索关键词
- **实时筛选**：输入即时生效，无需点击按钮

### 📋 列管理
- **列显示/隐藏**：灵活控制显示哪些列
  - 点击"列显示"按钮打开设置面板
  - 勾选/取消勾选来显示/隐藏特定列
  - 支持"显示全部"和"隐藏全部"快捷操作
  - 工具栏实时显示隐藏列数量
- **列排序**：点击表头对任意列进行升序/降序排序
  - 自动识别数字和文本类型
  - 支持多列排序切换

### 📤 导出功能
- **选择性导出**：选择特定列进行导出
- **保持格式**：导出的 TSV 文件保持原始格式
- **自定义文件名**：自动生成带"导出"后缀的文件名

### 🎨 界面优化
- **文本换行**：可切换单元格文本换行模式
- **分页显示**：支持 15/50/100/500 行每页
- **响应式设计**：适配桌面和移动设备
- **现代化 UI**：使用 Tailwind CSS 构建的美观界面

## 🚀 使用方法

### 快速开始

1. **打开应用**
   - 直接在浏览器中打开 `spa.html` 文件
   - 或使用本地服务器（推荐）

2. **上传文件**
   - 拖放 TSV 文件到上传区域
   - 或点击"选择文件"按钮

3. **浏览数据**
   - 使用搜索框查找内容
   - 使用 ID 筛选框过滤特定行
   - 点击表头进行排序

4. **管理列显示**
   - 点击工具栏的"列显示"按钮
   - 在弹出面板中勾选要显示的列
   - 隐藏不需要的列以聚焦重要信息

5. **导出数据**
   - 点击"导出"按钮
   - 选择要导出的列
   - 下载生成的 TSV 文件
